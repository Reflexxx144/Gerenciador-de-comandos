🐍 List Comprehension (Criar listas rápidas)
A forma mais famosa e elegante de criar listas filtradas em apenas uma linha.
quadrados = [x**2 for x in range(10) if x % 2 == 0]
🐍 Abrir arquivos com segurança (With Open)
O padrão correto para ler arquivos garantindo o fechamento automático.
with open("dados.txt", "r") as arquivo:
    print(arquivo.read())
🟨 Consumir API Rest (Fetch com Async/Await)
O comando padrão para buscar dados na internet de forma assíncrona.
async function buscarDados() {
    const resposta = await fetch('https://github.com');
    const dados = await resposta.json();
    console.log(dados);
}
